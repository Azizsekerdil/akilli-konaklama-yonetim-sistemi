# Smart Accommodation Management System — User Guide

## First start

1. Follow the installation steps in the repository README and start the application.
2. On the host computer, sign in with `admin` / `admin`.
3. Set a new, strong password when prompted. The temporary credentials cannot be used remotely or retained.

## Daily workflow

- Create rooms and rate plans before accepting reservations.
- Register guests, confirm dates, assign rooms, and use check-in/check-out actions.
- Record payments and review daily operational reports.
- Create named staff accounts with only the permissions they need.

Keep secrets in environment variables, never commit production data, and back up the database regularly. This project is provided under the MIT License without warranty; users are responsible for applicable legal requirements.
